# AI Prediction Quality Reviewer

a small and simple python project for reviewing ai model predictions against ground-truth labels.

## Features:

- Normalizes prediction and ground-truth text.
- Detects matches and mismatches.
- Uses confidence scores for classification. 
- Generates summary metrics.
- Validates agregation counts.

## scope 

this project was intentionally built using python core fundamentals only. 
concepts practiced:
- Variables
- Numbers
- Strings
- Lists
- Dictionaries
- Conditions
- Loops
- String methods
- Counters and aggregation
- Basic validation logic 
Functions, Classes, External libraries, and file handling are intentionally not used in this version.

## Run

```bash

python3 main.py

```
